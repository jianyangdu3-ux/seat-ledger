装好后像普通 App 一样打开，离线也能用，数据只存你自己的设备

重要别在微信 / QQ 里直接装
在微信、QQ 内置浏览器打开链接时，点不了"安装 / 添加到主屏幕"。请先点右上角 … 选「在浏览器打开」，再用手机自带的 Chrome / Edge / Safari 按下面步骤装。· 电脑直接用 Chrome / Edge 打开即可。

装好后要知道
  • 联网用过一次后，断网也能打开
  • 学生名单、座位、记录只存在你这台设备，开发者和其他人都看不到
  • 开发者改了功能，你打开刷新就是新版，不用重装
  • 万一误删图标，用同一个浏览器重装 / 重访问，数据还会在
